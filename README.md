# Ever Seen Depth Website

A simple static landing page for Ever Seen Depth.

## Files

- `index.html` — website structure
- `style.css` — website styling

## How to preview locally

Open `index.html` in your browser.

## How to deploy on Vercel

1. Create a GitHub repository.
2. Upload `index.html` and `style.css`.
3. Go to Vercel.
4. Import the GitHub repository.
5. Deploy.
6. Add the custom domain: `everseendepth.com`.
7. Follow Vercel's DNS instructions in your Squarespace domain settings.
